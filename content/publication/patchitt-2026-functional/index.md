abstract = "Individual differences in susceptibility to somatosensory false physiological feedback reflect variations in interoceptive processing, yet the underlying neural network mechanisms remain unclear. We analyzed resting-state functional connectivity using graph theoretical approaches in 41 healthy adults who completed a somatosensory false feedback paradigm. Nine regions of interest were defined from previous activation analyses, and network topology metrics including local efficiency, clustering coefficient, centrality measures, and path length were calculated across multiple thresholds. Three distinct patterns of network organization predicted false feedback susceptibility. Individuals more susceptible to false feedback showed: (1) increased posterior insula eccentricity, indicating network peripheralization of this key interoceptive region; (2) consistent orbitofrontal cortex segregation across multiple metrics including increased path length and decreased centrality measures; and (3) cerebellar network reconfiguration with reduced local efficiency but increased betweenness centrality. Somatosensory false feedback susceptibility reflects specific alterations in functional network topology, particularly reduced integration of interoceptive regions (posterior insula) and emotional appraisal systems (orbitofrontal cortex). These findings support a network-based model where interoceptive processing depends on efficient integration between visceral sensation, emotional evaluation, and cognitive control systems. Understanding these network properties may inform interventions targeting interoceptive awareness and emotional regulation."
